EL PROPÓSITO DEL CURSO

No se trata de aprender herramientas aisladas, sino de construir un sistema de investigación

La propuesta parte de un problema frecuente: los investigadores utilizan distintas aplicaciones para buscar literatura, comparar documentos, analizar datos, redactar, producir gráficos y preparar informes, pero cada actividad suele quedar separada de la siguiente. El curso muestra cómo conectar esas tareas para reducir duplicaciones, mantener trazabilidad y producir resultados que puedan revisarse y actualizarse.

01

Investigar con criterio

La IA se utiliza como apoyo para descubrir, organizar, comparar, revisar y explicar información. La selección de fuentes, las decisiones metodológicas y la interpretación permanecen bajo control del investigador.

02

Analizar de forma reproducible

R permite transformar datos, documentar procedimientos y generar resultados que pueden volver a ejecutarse. Esto reduce el trabajo manual y mejora la consistencia del análisis.

03

Publicar sin reconstruir

Quarto integra texto, código, tablas, gráficos y referencias en un mismo proyecto. GitHub conserva cambios, versiones y evidencia del proceso.

METODOLOGÍA DE TRABAJO

Investigación con IA y análisis reproducible en cuatro etapas

La dinámica replica el flujo de trabajo planteado para esta edición: ChatGPT ayuda a coordinar, revisar y explicar; OpenCode sirve como puente operativo con herramientas y código; y el proceso avanza desde el descubrimiento de evidencia hasta la publicación y verificación.

1

Descubrir

Objetivo: localizar evidencia relevante y ampliar el mapa de fuentes.

Herramientas: Consensus para búsqueda científica y ResearchRabbit para explorar artículos relacionados y conexiones entre trabajos.

Resultado: una base inicial de literatura y fuentes que pueda ser revisada por el investigador.

2

Contrastar

Objetivo: comparar documentos, identificar coincidencias y diferencias y revisar borradores o código.

Herramientas: Gemini para comparación documental y DeepSeek para apoyo en código y borradores.

Resultado: información contrastada antes de pasar al análisis.

3

Analizar

Objetivo: pasar de información y datos a resultados verificables.

Herramienta: R para limpieza, transformación, tablas, gráficos, estadística y comparación temporal.

Resultado: análisis documentado que puede volver a ejecutarse.

4

Publicar y verificar

Objetivo: producir una salida profesional sin separar redacción, código y resultados.

Herramientas: Quarto para publicación reproducible y GitHub para código, resultados y versiones.

Resultado: un producto final trazable y actualizable.

Principio transversal del curso:

La inteligencia artificial puede acelerar la búsqueda, la comparación, la escritura y el desarrollo técnico, pero no sustituye la verificación de fuentes, la selección metodológica ni la interpretación académica. El investigador valida fuentes e interpretación.

QUÉ PAPEL CUMPLE CADA HERRAMIENTA

Una arquitectura sencilla para saber cuándo usar cada recurso

ChatGPT

Coordina el proceso, ayuda a formular instrucciones, revisar argumentos, explicar resultados y organizar el trabajo entre etapas.

OpenCode

Conecta el trabajo con archivos, herramientas y código, facilitando la ejecución de tareas dentro del proyecto.

Consensus

Apoya la localización de literatura científica relevante y la exploración inicial de evidencia académica.

ResearchRabbit

Permite recorrer redes de literatura relacionada para descubrir trabajos que pueden no aparecer en una búsqueda lineal.

Gemini

Se utiliza como apoyo para comparar documentos y revisar materiales extensos desde otra perspectiva.

DeepSeek

Apoya tareas de programación, revisión de código y generación de borradores técnicos.

R

Es el motor de análisis: transforma datos, calcula resultados, crea tablas y gráficos y permite repetir el análisis cuando cambian los datos.

Quarto

Integra narrativa, código, referencias, tablas y gráficos en una publicación reproducible.

GitHub

Conserva versiones, registra cambios y permite mantener una fuente única de verdad del proyecto.

DINÁMICA PRÁCTICA

El curso se trabaja sobre un proyecto completo, no sobre ejemplos desconectados

Durante la sesión se seguirá una secuencia única: partir de una pregunta o necesidad de investigación, localizar y contrastar fuentes, organizar datos, ejecutar un análisis, interpretar resultados y producir una salida reproducible. La intención es que cada herramienta aparezca únicamente cuando resuelve una necesidad concreta del flujo.

1.Pregunta o problema claramente delimitado.
2.Fuentes localizadas y contrastadas.
3.Datos y análisis ejecutados en R.
4.Tablas y gráficos generados desde el código.
5.Reporte integrado en Quarto.
6.Proyecto organizado y versionado en GitHub.

PREGUNTAS FRECUENTES

Antes de inscribirse

¿Es un curso de programación?

No exclusivamente. R forma parte del flujo, pero el objetivo principal es integrar investigación, IA, análisis reproducible, publicación y control de versiones.

¿La IA hará la investigación por mí?

No. La IA se utiliza como apoyo para acelerar tareas y revisar información. La validación de fuentes, las decisiones metodológicas y la interpretación siguen siendo responsabilidad del investigador.

¿Necesito experiencia previa con R?

No se plantea como requisito dominar R de manera avanzada. El curso muestra su papel dentro del flujo completo y desarrolla ejercicios guiados.

¿Por qué usar Quarto?

Porque permite unir texto, código, resultados, tablas y gráficos en un mismo proyecto y volver a generar el documento cuando cambian los datos o el análisis.

¿Por qué usar GitHub?

Porque ayuda a conservar versiones, registrar cambios y mantener organizado el proyecto como una fuente única de verdad.

¿A quién conviene esta edición?

Especialmente a investigadores, docentes, consultores, profesionales de ciencias sociales y estudiantes de posgrado que ya trabajan con proyectos reales y quieren hacerlos más eficientes y reproducibles.
